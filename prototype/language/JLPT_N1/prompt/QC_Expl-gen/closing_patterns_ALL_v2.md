# JLPT解説「閉じの文」ライブラリ（A〜E統合版）

`Expl_gen`（解説文生成プロンプト）と併用する、解説末尾の1文（〆）の選択ライブラリ。
グループA〜Eを収録。**グループF（安全・防災・医療）は `groupF_closing_patterns.md` を参照。**

---

## 使い方（3ステップ）

### STEP 1：グループを判定（正解語ベース）

**第一原則：`correct_answer`（正解語）の意味でグループを決める。**
文中にどんな語が出るかではなく、その問題が問うている語がどの場面の語かで判断する。

| 群 | 種別 | 正解語がこういう意味なら |
|---|---|---|
| **F** | 安全・防災・医療 | 事故・災害・救助・応急・避難・予防・点検（→ `groupF_closing_patterns.md`へ） |
| **D** | 報道・公式・法律 | 発表・政策・法律・選挙・警察・改正・報道 |
| **C** | ビジネス | 契約・報告・製品・販売・実用化・再利用（実務・経済活動） |
| **B** | 会話・日常 | 友達・家族との交流、日常の動作・感情 |
| **E** | 文化・地域 | 伝統・信仰・地場産業など文化そのもの |
| **A** | 汎用（デフォルト） | 性格・様子・程度・感覚、モノの性質など場面を選ばない語 |

**優先度：F ＞ D ＞ C ＞ B ＞ E ＞ A**

**判定の鉄則**
1. 背景装飾に引っ張られない — 「大学は研究設備に恵まれ〜」で正解語が「恵まれ」→ A（研究・設備は装飾）
2. 同じテーマでも正解語で割れる — 環境系：正解語「生分解性・自然」→A、「再利用・実用化」→C
3. 現代日本の一般常識はAに倒す — ゴミ分別・ペット再利用など、根底が科学技術でも生活常識ならA
4. 迷ったら A（汎用）

### STEP 2：難易度でトーンを選ぶ

difficulty（1〜5）に応じて、下記の該当ブロックからパターンを1つ選ぶ。

| difficulty | トーン |
|---|---|
| 1・2 | 易しめ・成功体験・自信づけ |
| 3 | 標準 |
| 4・5 | 上級・到達度確認 |

### STEP 3：解説末尾に挿入

選んだ〆を、解説本体の末尾に `<br>` で繋ぐ。別問題なら同じパターンの再利用可。

## 共通ルール

| 難易度 | 解説表現レベル | ルビ適用基準 |
|---|---|---|
| **1〜3** | N3相当まで | N2以上の漢字にルビ |
| **4〜5** | N2相当まで使用可 | **N1相当の漢字のみルビ**（N2漢字は読めて当然のため省略） |

- ルビ形式：`漢字（かな）`（`<ruby>` タグ不使用）
- 送りがなのある語は読む部分だけ：`保（たも）つ`
- 目安 20〜30字
- グループFのみ深刻度（軽微/中度/重度）で分岐 → 別ファイル

# 難易度1（最易・基本の基本）

**トーン：絶対に落とさない・できた喜び**

### A：汎用
- いちばん基本の語です。ここは必ず正解しましょう！
- 毎日（まいにち）使う大事な言葉。すぐに覚えられます。
- やさしい語です。自信（じしん）を持って答えましょう。
- 基本中（きほんちゅう）の基本。ここができたら次に進めます。
- よく見る言葉です。しっかり覚えて得点源（とくてんげん）にしましょう。
- かんたんな語ですが、とても大切。確実（かくじつ）に取りましょう。

### B：会話・日常
- 毎日（まいにち）の会話でよく使う言葉。すぐに使えるようになります。
- 友達（ともだち）や家族との話に出てくる、身近（みぢか）な語です。
- やさしい会話表現（かいわひょうげん）。声に出して覚えましょう。
- 日常（にちじょう）でよく使う基本の語。ここは楽（らく）に取れます。

### C：ビジネス
- 仕事でもよく使う、やさしい語です。早めに覚えておきましょう。
- 基本のビジネス語。これから役立つので今のうちに。
- 職場（しょくば）で耳にする言葉です。かんたんなので確実（かくじつ）に。
- 仕事の基本の語。覚えておくと将来（しょうらい）に役立ちます。

### D：報道・公式
- ニュースでもよく聞く言葉です。基本なので覚えておきましょう。
- やさしい公的（こうてき）な語。少しずつ慣（な）れていきましょう。
- 新聞（しんぶん）にも出る基本の語。ここは押（お）さえておきたい問題です。

### E：文化・地域
- 日本の文化（ぶんか）に関わる、やさしい語です。楽しく覚えましょう。
- 身近（みぢか）な文化（ぶんか）の言葉。知っておくと役立ちます。
- 伝統（でんとう）に関わる基本の語。日本らしさを感じてください。

# 難易度2（易・基本を固める）

- 基礎（きそ）を固（かた）める大切な語。丁寧（ていねい）に覚えましょう。
- 読めて当然（とうぜん）にしたい語。あと少しで身（み）につきます。

### B：会話・日常

- 日常（にちじょう）でよく登場（とうじょう）する語。しっかり覚えましょう。
- 身近（みぢか）な表現（ひょうげん）。会話で使えると便利（べんり）です。

### C：ビジネス
- 仕事でよく使う語。基本として押（お）さえておきましょう。
- ビジネスの基礎（きそ）となる語。早めに覚えると安心（あんしん）です。
- 職場（しょくば）で役立つ言葉。しっかり身（み）につけましょう。
- 報告（ほうこく）や連絡（れんらく）で使う基本語。確実（かくじつ）にしたい問題です。
- 仕事の場面で出る語。覚えておくと後（あと）が楽（らく）になります。

### D：報道・公式
- ニュースでよく使われる語。時事（じじ）に慣（な）れる第一歩（だいいっぽ）です。
- 公的（こうてき）な文書（ぶんしょ）に出る基本語。少しずつ覚えましょう。
- 新聞（しんぶん）でよく見る語。読めると世界（せかい）が広がります。

### E：文化・地域
- 文化（ぶんか）に関わる基本の語。背景（はいけい）と一緒（いっしょ）に覚えましょう。
- 伝統（でんとう）や地域（ちいき）の言葉。知ると日本語（にほんご）が楽しくなります。
- 日本らしい表現（ひょうげん）。使えると語彙（ごい）が豊（ゆた）かになります。

# 難易度3（標準）

**トーン：標準的な励まし**

### A：汎用
- 押（お）さえておきたい基本の語です。
- ここをしっかり理解（りかい）したら、JLPT学習が一段階進みます。
- 意外（いがい）と大事な語。確実（かくじつ）に覚（おぼ）えましょう。
- どの場面でも使える、大事な言葉です。ここは必ずできるようにしましょう。
- 読めるだけでなく、書いて使えるレベルを目指しましょう。
- 基本の語ですが、奥（おく）が深い。この先も何度も出ます。

### B：会話・日常
- 毎日（まいにち）の会話で自然（しぜん）に使える大事な語。会話の中で使い分（わ）けられるようになりましょう。
- 友達（ともだち）や家族との話に出てくる身近（みぢか）な表現（ひょうげん）です。今のうちに慣（な）れておきましょう。
- 会話では別の言葉で言うことも多いですが、覚えておくと便利（べんり）です。
- 身近（みぢか）な場面でよく使う語。ここは必ず正解したい問題です。

### C：ビジネス
- ビジネスメールや公式（こうしき）文書に頻出（ひんしゅつ）。ここで落とさないようにしましょう。
- 仕事の場面でよく使う語。これから実務（じつむ）に進むなら覚えておきたい問題です。
- ビジネス文書では使いますが、会話ではあまり出ません。場面（ばめん）による使い分（わ）けを意識（いしき）してください。
- 職場（しょくば）でよく使われる表現（ひょうげん）。実用的（じつようてき）な理解が大事です。
- 報告（ほうこく）や調整（ちょうせい）の場面で登場します。丁寧（ていねい）に覚えましょう。
- 仕事の語彙（ごい）として重要（じゅうよう）です。使えると印象（いんしょう）が変わります。

### D：報道・公式
- 報道や公式（こうしき）文書によく出ます。ここで読み落とさないようにしましょう。
- 時事問題（じじもんだい）やニュースに登場します。背景（はいけい）とセットで覚えると定着（ていちゃく）します。
- 公的（こうてき）な場面で使う硬（かた）い表現（ひょうげん）。読めれば十分な問題です。
- 法律（ほうりつ）や社会（しゃかい）の話題に出ます。正確（せいかく）な理解が求められます。

### E：文化・地域
- 読み方や使い方に工夫（くふう）がある語。ここで理解（りかい）できたら力がつきます。
- 簡単（かんたん）に見えますが、日本語ならではの使い方があります。文化（ぶんか）を感じ取ってください。
- 地域（ちいき）や伝統（でんとう）に関わる語。背景（はいけい）を知ると覚えやすくなります。
- 読める力と使える力は違（ちが）います。似（に）た言葉と一緒（いっしょ）に学ぶといいですよ。

# 難易度4（やや難）

**トーン：あと一歩で上級・到達度確認**

### A：汎用
- 少し難しい語ですが、ここが読めると力が確実（かくじつ）につきます。
- 中級から上級への橋渡し。しっかり覚えたい問題です。
- 正確（せいかく）に読める人は多くありません。差をつけられる語です。
- 意味も読みも少し複雑（ふくざつ）。ここを越えれば一段上です。
- 文章でよく見かける語。読解力（どっかいりょく）の土台になります。
- あと一歩で上級。丁寧に理解しておきましょう。
- 読める力は積み重ね。ここで確実（かくじつ）に押さえましょう。
- 上級語彙（ごい）の入り口となる語。今が覚えどきです。
- 苦手にしている人が多い語です。ここで克服（こくふく）しておきましょう。

### B：会話・日常
- 会話（かいわ）で使えると自然（しぜん）さが増（ま）します。少し難（むずか）しいですが挑戦（ちょうせん）を。
- 親（した）しい間柄（あいだがら）で使う、少し大人（おとな）びた表現（ひょうげん）です。
- 日常（にちじょう）でさりげなく使えると印象（いんしょう）が変わる語です。
- やや難（むずか）しい会話表現（かいわひょうげん）。使いこなせると一目置（いちもくお）かれます。

### C：ビジネス
- ビジネスで一目置（いちもくお）かれる語。上級者（じょうきゅうしゃ）として押（お）さえたい問題です。
- 公式（こうしき）な文書（ぶんしょ）で使う少し硬（かた）い語。実務（じつむ）で差（さ）が出ます。
- 会議（かいぎ）や交渉（こうしょう）の場で登場（とうじょう）します。使えると信頼（しんらい）につながります。
- やや専門的（せんもんてき）なビジネス語。読めるだけで一歩（いっぽ）リードできます。
- 報告書（ほうこくしょ）や企画書（きかくしょ）に出る語。書けるレベルを目指しましょう。
- 上級（じょうきゅう）のビジネス語彙（ごい）。ここまで理解（りかい）できれば十分（じゅうぶん）です。

### D：報道・公式
- 新聞やニュースが読めるレベルの語。時事に強くなれます。
- 公的な文書に出る硬い語。読解の幅が広がります。
- 報道でよく使われる語。社会の動きを理解する力になります。
- 法律や政治の記事に登場。上級読解（じょうきゅうどっかい）への一歩です。
- 知識として持っておきたい語。社会を読む力になります。
- 報道と日常をつなぐ語。読解（どっかいりょく）がぐっと楽になります。
- 公式な場面に出る語です。知っていると読み飛ばさずに済みます。

### E：文化・地域
- 文化的（ぶんかてき）な背景（はいけい）を持つ語。日本らしさが深（ふか）く理解（りかい）できます。
- 少し古風（こふう）な響（ひび）きの語。教養（きょうよう）として知っておきたい言葉です。
- 伝統（でんとう）や地域（ちいき）に根（ね）ざした語。奥深（おくぶか）さを味わってください。
- 文化（ぶんか）の香（かお）りがある表現（ひょうげん）。使えると語彙（ごい）の幅（はば）が広がります。

# 難易度5（難・上級）

**トーン：ここが読めれば上級者**

### A：汎用
- かなり難しい語。ここが読めれば上級者と言えます。
- 正確に読める人は少ない、難関（なんかん）の語です。自信を持ちましょう。
- 上級レベルの語彙（ごい）。読めたら大きな自信になります。
- 難しい読みですが、ここまで来たら本物の実力です。
- 上級者でも迷う語。マスターできれば頼もしい一問です。
- 難関（なんかん）の語。読めるかどうかが本当の実力を分けます。
- N1にも通じる難しさ。読めれば語彙力（ごいりょく）は本物です。
- ここが読めるかどうかで差が最もつく問題の一つです。
- 一段上を目指す人だけが知っている語。到達（とうたつ）の証です。

### B：会話・日常
- 上級者（じょうきゅうしゃ）でも使いこなすのが難（むずか）しい会話表現（かいわひょうげん）です。
- ネイティブらしい、こなれた言い回（まわ）し。使えれば会話（かいわ）の質（しつ）が上がります。
- さりげなく使えると一目置（いちもくお）かれる、上級（じょうきゅう）の日常表現（にちじょうひょうげん）です。
- 難（むずか）しい口語表現（こうごひょうげん）。理解（りかい）できれば自然（しぜん）な日本語に近づきます。

### C：ビジネス
- 高度（こうど）なビジネス語。使いこなせれば一流（いちりゅう）の印象（いんしょう）を与（あた）えます。
- 専門的（せんもんてき）な実務（じつむ）で使う難（むずか）しい語。読めれば十分（じゅうぶん）に上級（じょうきゅう）です。
- 公式文書（こうしきぶんしょ）でも上位（じょうい）の硬（かた）い語。ここまで来れば頼（たの）もしい。
- 経営（けいえい）や交渉（こうしょう）の高度（こうど）な場面で登場（とうじょう）する語です。
- 上級（じょうきゅう）ビジネス語彙（ごい）の代表格（だいひょうかく）。マスターして損（そん）はありません。
- 難関（なんかん）の実務語（じつむご）。読めるだけで確（たし）かな力（ちから）の証（あかし）です。

### D：報道・公式
- 難しい報道用語。社説や専門記事も読めるレベルです。
- 法律や行政の専門的な語。上級読解の証です。
- 硬い公的表現の上位。ここが読めれば新聞は怖くありません。
- 専門性の高い時事語。理解できれば社会人として頼もしい。
- 政治・経済の記事が読めるレベルです。情報の見え方が変わります。
- 専門家も使う語彙（ごい）です。理解できれば議論についていけます。
- N1レベルにも出る語。ここを読める力が上位合格を支えます。

### E：文化・地域
- 深（ふか）い文化的教養（ぶんかてききょうよう）を示（しめ）す語。知っていると一目置（いちもくお）かれます。
- 古典（こてん）や伝統（でんとう）に根（ね）ざした難（むずか）しい語。日本文化（にほんぶんか）の奥行（おくゆ）きです。
- 上級（じょうきゅう）の文化語彙（ぶんかごい）。使いこなせれば表現（ひょうげん）に深（ふか）みが出ます。
- 教養（きょうよう）のある大人（おとな）の語。読めれば日本語（にほんご）の世界（せかい）が広がります。
