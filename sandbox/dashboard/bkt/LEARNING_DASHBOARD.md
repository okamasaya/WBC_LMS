# N2学習ダッシュボード：今回のブレイクポイント

SQLiteを標準入力に、数値・大問題別正解率・理解度・サマリーを確認する初版です。添付イメージの配置を参考に、現在のデータに合わせてN2言語知識（文字・語彙・文法）の9大問題を表示します。

## 起動

リポジトリ直下（WBC_LMS）から、既存のPython環境で実行します。

```sh
python -m sandbox.dashboard.bkt.learning_dashboard
```

http://127.0.0.1:8056 を開きます。SQLite・5回・150回答を最初から表示します。新しい画面はlearning_dashboard.py、既存のモデル検証画面flat_app.pyは8055のままです。追加パッケージは不要です。

現在のフォルダーがsandbox/dashboard/bktなら、1つ上に移動して起動してください。`-m`に`.py`を付けません。

```sh
cd ..
python -m bkt.learning_dashboard
```

## 表示と指標の定義

| 表示 | 定義 |
|---|---|
| 正解率 | 回答済みで有効な正誤のある回答の正解割合。補助項目が不正でも有効な正誤の集計からは落とさない |
| 解説後の理解度 | 自己申告0〜3の平均。未入力・不正値を分母から外す。0は有効値 |
| モデル試算の平均 | 既存の3項目補助モデルによる各回答のAssistedAfterLearningの平均。手動の仮定による独立回答の試算 |
| 平均回答時間 | 有効なResponseTimeMsの平均を秒に換算。解説閲覧を含む総学習時間ではない |
| 実施回数・回答数 | 選択条件内の実施回数・問題数・有効回答数 |
| 大問題別正解率 | 対象期間内の直近3回を比較。大問題は既存SkillIDの9項目 |
| 実施回ごとの推移 | 自己申告理解度／モデル試算／正解率を切替。それぞれの目盛・意味を保持 |
| サマリー | 最新回、前回との正解率差（ポイント）、正解率が最も低い大問題と件数、自信度1・2で不正解だった件数。集計ルールによる表示 |
| データの状態 | 未回答、自己申告の未入力・不正、推定除外の件数 |

モデル試算は累積習得率・検証済み理解度ではありません。推定信頼度や信頼区間を計算した表示でもありません。画像にあるAI推薦や推測正解率などは、定義と検証を決める次の仕様に残しています。N1・読解・聴解のデータは今回含めていません。

## 連動と出力

- 学習者・対象期間・大問題で絞ると、数値、グラフ、サマリー、履歴・明細と出力対象が同じ条件になります。
- 大問題の棒をクリックしても絞り込めます。「大問題の選択を解除」で全大問題へ戻ります。
- SQLite（標準）とCSV（同内容の控え）を切替可能。入力元の変更時は、そのデータの全期間・全大問題から表示し直します。
- 大問題サマリー・実施履歴・回答明細のCSVと、モデル仮定JSONを保存できます。表のページだけでなく、選択条件に合う全対象です。
- CSVのAccuracy／ModelMeanは0〜1、Understandingは0〜3、AverageSecondsは秒。モデル明細は推定対象の有効回答です。モデル仮定JSONには条件・パラメータ・補助重み・モデル版を含めます。
- 対象0件は数値を「—」とし、読み込み失敗や不正な期間では前の結果を保持しません。

## SQLiteとCSV控え

主入力は[data/mock_jlpt_n2_5_sessions/learning_logs.sqlite3](data/mock_jlpt_n2_5_sessions/learning_logs.sqlite3)。DBは読み取り専用で、画面操作では変更しません。

同じ5表のCSVを[data/mock_jlpt_n2_5_sessions/csv/](data/mock_jlpt_n2_5_sessions/csv/README.md)へ保存しました。SQLiteの値・型と対応し、SHA-256・件数をmanifestに残しています。現行prototypeの41列エクスポートとは別の、保存用5表の控えです。

```sh
# DBから控えを再生成。同じ内容なら変更なし、異なる既存内容は保護する
python -m sandbox.dashboard.bkt.dashboard_data --export-csv
# DBの更新をCSVへ明示的に反映する場合のみ --overwrite
```
