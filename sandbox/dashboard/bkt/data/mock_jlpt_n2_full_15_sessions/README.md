# N2全領域・15回の架空学習ログ

架空学習者1人、15回、各107問、合計1,605回答。SQLiteを主データに、同じ5表のCSVを`csv/`に保存。既存の5回・150回答と20回・600回答は変更していません。

## 配分と出典

利用者添付「JLPT_試験ガイドブック.pdf」の「新しい日本語能力試験ガイドブック」、冊子21ページのN2表を参照しました。PDF作成メタデータは2009年。原本PDFは複製せず、SHA-256をmanifestへ記録しています。原文では小問数は目安で変更の場合があると明記されています。現行試験の固定配分とは扱いません。

| 領域 | 大問と小問数／回 | 計／回 | 15回の回答数 |
|---|---|---:|---:|
| 言語知識 | 漢字読み5、表記5、語形成5、文脈規定7、言い換え類義5、用法5、文法形式の判断12、文の組み立て5、文章の文法5 | 54 | 810 |
| 読解 | 内容理解〈短文〉5・〈中文〉9、統合理解2、主張理解〈長文〉3、情報検索2 | 21 | 315 |
| 聴解 | 課題理解5、ポイント理解6、概要理解5、即時応答12、統合理解4 | 32 | 480 |

19件のSkillは領域を含むIDで識別します。資料の大問番号は言語知識・読解で1〜14、聴解は1〜5。読解と聴解の「統合理解」を混同しません。

`CategoryLevel1`＝3領域、`CategoryLevel2`＝文字・語彙／文法／内容理解等、`CategoryLevel3`＝大問名・短文／中文／長文。「分類」は画面整理用の階層で、資料にない下位技能は追加していません。

## 形式と指標

- `learning_logs.sqlite3`：Student 1件、Skill 19件、Question 1,605件、Session 15件、QuestionResult 1,605件。
- `schema.sql`：既存5表形式。主キー・外部キー、自信度・理解度の範囲、回答位置と正誤の一致を制約。
- `csv/*.csv`：全5表と同じ列・値。UTF-8 BOM、真偽値TRUE/FALSE。型はschema.sqlに従います。
- `manifest.json`：seed、分類・配分、件数、PDF・生成コード・各成果物のSHA-256、制約事項。

全回答済み。自信度は既存と同じく**1が高く4が低い**、解説後理解度は**0が低く3が高い自己申告**です。正答率と自己申告とモデル試算は別指標です。`Session.ScoreRate`は正答率を0〜100の整数に丸めた値で、公式尺度得点ではありません。画面では正答数／回答数と正答率を表示します。合否判定・累積習得率は生成しません。

各回で異なる合成QuestionIDを生成します。問題文・本文・解説・音声は未作成、選択位置や難易度も合成値です。共通素材の設問群、本試験の音源進行は再現していません。時刻は架空の操作記録で、解説閲覧・理解度記録は受験終了後。実際の聴解の所要時間測定には使えません。

領域・大問ごとの偏り、回ごとの変動、緩やかな改善を含む乱数で正誤を生成します。自信のある誤答や自信の低い正答も含みます。推定モデルから正誤を生成していません。実績・モデル精度・学習効果の証拠ではありません。


```python
from sandbox.dashboard.bkt.full_learning_dashboard import load_full

```
